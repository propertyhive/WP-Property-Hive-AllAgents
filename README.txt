Quickly and easily display ratings and reviews from AllAgents, plus customisation options

== Description ==


Display allAgents ratings and customer reviews directly on your WordPress website. Build trust with prospective buyers, sellers, landlords and tenants using easy-to-embed estate agent review widgets.

The **Property Hive allAgents Review Embed** plugin makes it simple to showcase customer reviews from your allAgents profile on any WordPress website.

Designed for estate agents and letting agents, the plugin supports two integration methods: quickly embed an existing allAgents review widget, or use the allAgents API for greater control over the appearance and layout of your reviews.

Simply configure your review widget and add a shortcode to any WordPress page or post.

= Features =

* **Display allAgents reviews on WordPress** - Showcase customer ratings and reviews from your allAgents profile directly on your website.
* **Two integration methods** - Choose between standard allAgents widgets or the more customisable API integration.
* **Easy widget embedding** - Add an existing allAgents review widget using its embed code.
* **Customisable review layouts** - Display reviews in a list or carousel when using the API integration.
* **Firm or branch-specific reviews** - Choose whether to display reviews for your entire agency or an individual branch.
* **Control the number of reviews** - Specify how many reviews should appear in your API-powered widget.
* **Customisable appearance** - Show or hide the header and footer, and customise the header background colour.
* **Multiple review widgets** - Create different review displays for different pages, branches or sections of your website.
* **Easy shortcode integration** - Add reviews to any WordPress page or post using a simple shortcode.
* **Works independently** - Compatible with any WordPress website. Property Hive is not required.

= Two Ways to Display allAgents Reviews =

The plugin offers two integration methods depending on how much control you need over the appearance of your customer reviews.

**Option 1: Standard allAgents Widget**

The simplest way to get started is by embedding an existing review widget provided by allAgents.

1. Obtain your review widget embed code from allAgents.
2. Create a widget in the plugin settings.
3. Select the AllAgents Widget integration type.
4. Paste your widget code into the provided field.
5. Add the generated shortcode to your website.

This option is ideal for agents who want a quick and straightforward way to display their allAgents reviews without configuring an API integration.

**Option 2: Customisable allAgents API Integration**

For greater control over the appearance and content of your reviews, the plugin also supports integration with the allAgents API.

This option is available to **allAgents Premium Support Plus members** and requires an API key obtained through your allAgents account.

The API integration provides additional configuration options, including:

* **Firm or branch reviews** - Display reviews for your entire estate agency or a specific branch.
* **List or carousel display** - Choose how customer reviews are presented.
* **Number of reviews** - Set how many reviews should be displayed.
* **Optional header** - Choose whether to display a header above your reviews.
* **Header background colour** - Customise the header to better match your website's branding.
* **Optional footer** - Choose whether to display a footer beneath your reviews.

This makes it easier to create review displays that complement your website's design and show the most relevant customer feedback.

= Perfect for Estate Agents and Letting Agents =

Customer reviews can play an important role when someone is choosing an estate agent or letting agent.

By displaying your allAgents ratings and reviews directly on your website, you can help prospective clients see feedback from previous customers without needing to visit another website.

Whether you're showcasing reviews on your homepage, a dedicated testimonials page or individual branch pages, this plugin makes it easy to bring customer feedback into your website.

If your estate agency operates across multiple locations, the API integration allows you to display reviews for your entire firm or an individual branch.

Create separate review widgets for different branches and display relevant customer feedback on each branch's page.

This can be particularly useful for larger agencies looking to showcase their reputation at a local level.

= How to Add allAgents Reviews to WordPress =

Getting started is simple:

1. Install and activate the Property Hive allAgents Review Embed plugin.
2. Open the plugin settings in your WordPress dashboard.
3. Create a new review widget.
4. Choose between the standard allAgents Widget or allAgents API integration.
5. Configure the available settings for your chosen integration method.
6. Copy the shortcode for your review widget and add it to any WordPress page or post.

The shortcode uses the following format:

`[allagents id="X"]`

Replace `X` with the ID of your configured review widget.

= Do I Need Property Hive? =

**No!** Although developed by the creators of [Property Hive](https://wordpress.org/plugins/propertyhive/), this allAgents review plugin is completely standalone.

You don't need to have Property Hive installed or be using it to manage your properties. Simply install the plugin, configure your review widgets and start displaying allAgents reviews on your website.

= Important Information =

The standard allAgents widget integration uses embed code provided by allAgents.

The advanced API integration requires an allAgents Premium Support Plus membership and a valid API key. Availability of API access is determined by allAgents.

== Installation ==

= Automatic installation =

Automatic installation is the easiest option as WordPress handles the file transfers itself and you don’t need to leave your web browser. To do an automatic install of Property Hive, log in to your WordPress dashboard, navigate to the Plugins menu and click Add New.

In the search field type “Property Hive AllAgents” and click Search Plugins. Once you’ve found our plugin you can view details about it such as the point release, rating and description. Most importantly of course, you can install it by simply clicking “Install Now”.

= Manual installation =

The manual installation method involves downloading the plugin and uploading it to your webserver via your favourite FTP application. The WordPress codex contains [instructions on how to do this here](http://codex.wordpress.org/Managing_Plugins#Manual_Plugin_Installation).

= Updating =

Updating should work like a charm; as always though, ensure you backup your site just in case.

= The Shortcode =

Simply add the shortcode [allagents id="X"] where you want it to appear. Visit the setting area to get the full shortcode.
